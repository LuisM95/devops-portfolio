# Git Advanced Notes 

## Useful Commands 

### Log

- `git log --oneline` - compatc history
- `git log --graph` - visual branch history 
- `git show <hash>` - show commit details 
- `git blame <file>` - who wrote each line

### Branches 

- `git branch` - list branches
- `git checkout -b <name>` - create and switch branch 
- `git merge <branch>` - merge branch into current
- `git branch -d <name>` - delete branch  

## Conflict Resolution
- This line was written in main branch
- This line was written in feature branch
- Conflicts happend when two branches modify the same line
